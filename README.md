# Dan's Art Projects

Welcome to **Dan's Art Projects**, a curated collection of immersive experiments and finished pieces that blend WebXR, generative AI, and bleeding-edge tools. This repository serves as both a portfolio and a sandbox where I document learnings, prototypes, and full releases across different mediums and devices.

## Vision

I explore how art changes when interaction, intelligence, and spatial computing converge. Each project starts with a question—*What happens if we mix humans, code, and environments in new ways?*—and then iterates through rapid prototyping until the answer feels expressive and delightful.

## Focus Areas

- **WebXR Installations:** Browser-based immersive experiences designed for headsets and mobile AR. I experiment with physics-driven storytelling, room-scale galleries, and collaborative spaces.
- **Generative AI Experiments:** Custom pipelines that leverage diffusion, transformers, and procedural shaders to co-create visuals, audio, and behavior. Prompt engineering doubles as a sketchbook.
- **Emerging Tech Pilots:** Hands-on trials with new frameworks, sensors, and interfaces. If a fresh API or device drops, I push it toward artful interaction as quickly as possible.

## Repository Structure

While the layout evolves, most projects include:

- `concept/` – Research notes, moodboards, and sketches that anchor the idea.
- `prototype/` – Proof-of-concept builds, often WebXR scenes or AI pipelines.
- `production/` – Polished pieces with build scripts, deploy instructions, and assets.
- `docs/` – Dev logs, talks, and walkthroughs for anyone curious about the process.

## Highlights

- **Spatial Story Seeds:** A set of WebXR mini-worlds where visitors unlock vignettes through motion, gaze, and gesture.
- **DreamTexture Studio:** A generative AI toolkit that turns live prompts into material libraries for XR fabrication.
- **Sensorium Sketches:** Multimodal installations combining voice, biometric sensors, and procedural visuals to mirror audience emotion.

## Getting Started

Each project folder contains a README with setup steps, but the typical workflow looks like:

```bash
git clone https://github.com/dannblair/GithubArt.git
cd GithubArt/<project>
npm install # or pnpm/yarn depending on the project
npm run dev
```

For AI-driven pieces you'll also find environment variable examples (`.env.example`) covering API keys, model endpoints, and GPU configuration.
